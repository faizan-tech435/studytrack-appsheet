# StudyTrack

A simple student task tracker built with a no-code platform.

## Purpose
Helps a student track study tasks, with subject, due date, status and priority.

## Platform and tools
- Google Sheets (data source)
- Google AppSheet (no-code app builder, part of Google Cloud)
- Glide (tried first, but its free plan ran out of AI credits)

## Build steps
1. Created a Google Sheet named StudyTrack with columns: Task, Subject, Due Date, Status, Priority.
2. Added sample task rows.
3. In Google Sheets, opened Extensions > AppSheet > Create an app.
4. AppSheet generated the app from the sheet, with a task list and an add form.
5. Tested by adding a task in the app and checking that the new row appeared in the sheet.

## Features
- View tasks grouped by status
- Add, edit and delete tasks
- Data stays synced with the Google Sheet

## AI use
AppSheet and Glide generate the app screens automatically from the sheet data.
